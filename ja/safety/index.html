強い制限より先に、安全な解除を設計しました。

できること・できないこと

Focus Bombは、Appleの Screen Time API を使用し、対応するアプリとWebサイトを広範囲に制限します。 これは「iPhone全体を完全に操作不能にする」機能ではありません。iOSの仕様、端末設定、システム機能に よって、通常電話、緊急機能、一部のシステム画面など、アプリから完全には制限できない操作が残る場合が あります。

言い切らないこと。 「電話以外を完全にロックする」「絶対に解除できない」「100%安全」とは説明しません。 Focus Bombは広範囲の制限を提供しますが、iOSの仕様上の制約は常に存在します。

絶対最大終了時刻

集中セッションを開始する前に、通常終了時刻と「最悪の場合」の絶対最大終了時刻の両方を表示します。 絶対最大終了時刻は min(開始時刻 + 予定時間 × 3, 予定終了時刻 + 120分) で計算され、 誤答によるペナルティを含めても、この時刻を超えて延長されることはありません。

緊急解除

集中中の画面と警告室には、常に緊急解除ボタンが表示されています。7秒間長押しすると、 Face ID・パスコード・ネットワーク接続・広告視聴を必要とせず、即座にシールドが解除されます。 緊急解除を行った場合、そのセッションのFocus Scoreは0になり、公式ランキングの対象外になります。

フェイルオープン（Fail-open）設計

次のいずれかが発生した場合、Focus Bombは常に「解除する」側に倒れるよう設計されています。 「念のため制限を続ける」という判断はしません。

  • 保存データ（App Groupのenvelope）の破損やHMAC検証失敗
  • 共有Keychainからの鍵読み取り失敗
  • Screen Time権限の喪失・取消
  • 端末の時計変更を検知した場合（延長は行わず、unverifiedとして扱う）
  • アプリの強制終了・端末の再起動後、起動時に期限超過を検知した場合

サーバー・広告・課金の障害時

Focus Bombのロック解除処理は、サーバー・広告・課金・Game Center・チーム機能から独立しています。 これらのいずれかが停止・遅延・エラーになっても、集中セッションはローカル（端末内）で継続し、 予定通りに解除されます。

チームの安全設計

チーム機能（Feature Flag有効時）でも、ホストや他のメンバーが自分の端末のロック時間を 変更することはできません。各端末は独立して解除されます。

60秒安全テスト

初回利用時、OSの大型アップデート後、Screen Time再認証後、実装バージョンが変わった後には、 60秒間の安全テストが必須です。シールドを実際に適用し、ホーム画面に戻って対象アプリが 制限されることを確認し、Focus Bombへ戻って解除を確認します。安全テストに合格しない限り、 本番の集中セッションは開始できません。

推奨しない利用状況

  • 運転中
  • 医療・介護・育児の緊急対応が必要な時間
  • 災害・避難が想定される状況
  • 乗車券、Wallet、決済、地図、本人確認が必要な時間
  • 電話を含む緊急連絡手段を事前に確認できていない場合

電話・緊急SOSについて

通常の電話の発着信は、iOSの仕様上、Focus Bombのシールド中も利用できます。ただし、 実機での挙動確認はApple公式のScreen Time実装に依存するため、開始前に別の手段でも 緊急連絡が取れることを確認してください（出発前確認チェックリストで案内します）。

不具合の報告

パズルの不具合（正解が複数に見える、ヒントが矛盾している等）や安全上の懸念を発見した場合は、 結果画面の報告ボタン、またはサポートページからご連絡ください。
