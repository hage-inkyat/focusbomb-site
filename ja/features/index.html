機能

集中セッション

  • 15分から（Proは240分まで5分刻み）の時間設定
  • 対応するアプリ・Webサイトの広範囲な制限
  • 最大終了時刻の事前表示
  • 7秒長押しの緊急解除

パズル生成エンジン

  • 属性消去・配線経路・記号変換・数値/偶奇・論理ゲート・順列回転の6カテゴリ
  • 決定論的seedからの自動生成、正解一意性を自動検証
  • Lv1〜5の難易度（Lv4/5はPro）

記録・スコア

  • Focus Score・Defusal Rating
  • Game Centerランキング・実績
  • 結果シェアカード

Proプラン

  • セッション無制限、自由な時間設定
  • 詳細分析・長期履歴
  • 全テーマ・高品質シェア
  • 強制広告なし
