Security

Overview

Focus Bomb is local-first by design, minimizing what any server ever handles. Release logic itself never depends on our servers.

App Attest

We use Apple's App Attest to verify device integrity. A failed App Attest check never affects your local session or release — it only limits official leaderboard submission.

Webhook signature verification

Webhooks from Apple and Google are signature-verified before we act on them.

Data minimization, encryption, retention

Identifiers are stored hashed; raw credentials (App Attest assertions, full StoreKit JWS) are deleted within 24 hours. See the Privacy page for details.

Incident response

In a security incident we stop write APIs, rotate keys, scope the impact, and notify affected users if warranted, in that order.

Responsible disclosure

Found a vulnerability? Contact us via the address in /.well-known/security.txt. There is currently no paid bug bounty program.

Please don't: attempt to access real user data, perform any attack that degrades service, or disclose third-party data.
