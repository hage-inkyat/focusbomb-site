Support

Quick checks

  • Not releasing? Try the 7-second emergency-release hold first (free, no network required).
  • Not getting notifications? Check notification permission in Settings. Focus itself still works without it.
  • Being asked for Screen Time permission? Go to Settings > Screen Time and allow access for Focus Bomb.

About release behavior

See the Safety page for details.

Restore purchases

Use "Restore Purchases" in Settings to restore a prior Pro purchase. Restoration happens through the App Store; Focus Bomb never keeps its own separate account record of it.

About teams

See the Teams page for team-related questions.

Deleting your data

From Settings, you can delete your focus history, achievements, public results, or all local data at any time. See the Privacy page for details.

Contact us

Open an issue on GitHub (typical response time: 48–72 hours). The same details are available from the in-app Settings screen. Please include:

  • Issue category
  • App version
  • iOS version
  • Description of the issue

Please don't include personal details like restricted app names or call history. That tracker is public — anyone can read what you post.

Reporting a security issue

Found a vulnerability? Please follow the Responsible Disclosure steps on the Security page.
